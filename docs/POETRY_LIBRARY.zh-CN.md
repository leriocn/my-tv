# 诗词库维护

电视从 U 盘根目录的 `poetry` 读取诗词，和照片 `tv`、图片缓存 `.tvcache` 并列。照片与缓存不参与诗词播放。

```text
poetry/
  poems.json
  audio/
    p001.m4a
    p002.m4a
    ...
  sources.json
  listening-sources.json
  listening-segments.json
  使用说明.txt
```

`poems.json` 为 UTF-8 文本，`version` 保持为 `1`，`poems` 数组顺序就是轮播和熏听顺序。每首的 `id` 要唯一并保持稳定，播放进度按它保存；修改标题或释义不会丢失位置。更改后离开页面再回主页，或重新进入熏听即可读取。错误文件不会使桌面崩溃，会回退到内置文字并在熏听页显示读取状态。

每首的主要字段：

| 字段 | 内容 |
|---|---|
| id | 稳定编号，例如 p001；不要重复 |
| grade / term | 年级 1–5 / 上册 1、下册 2 |
| title / dynasty / author | 题目、朝代、作者 |
| lines | 原诗字符串数组；每个元素为显示的一行或一联 |
| meaning | 简明诗意，支持换行；释义音频朗读此内容，修改后需重新生成音频 |
| audio | 相对路径，例如 audio/p001.m4a；支持 m4a、mp3、ogg、opus、wav |
| listeningAudio | 可选的精简朗诵，例如 audio/p001-human.m4a；存在此字段时优先播放，原 audio 保留 |
| meaningAudio | 释义音频，例如 audio/p001-edge-meaning.m4a；缺失时提示补充音频，可重试或手动切歌 |
| narrator | 真人朗读者名称 |
| source / audioSource | 文本参考页、朗读来源页，便于复核 |

音频替换时，可保持文件名，或修改 `audio`。不得使用绝对路径、网络地址、子目录跳转。最多 256 个条目、JSON 不超过 2 MiB；建议保留一份修改前的副本。

当前整理的是人教版/统编六三学制一至五年级十册的诗、词、乐府及教材节选，包含语文园地，不包含现代白话诗、小古文和名句扩写。共 87 个教材条目，含《游子吟》《黄鹤楼送孟浩然之广陵》跨册复习。各册数量依次为 6、7、7、7、10、9、10、10、10、11。近年教材调整了篇目和顺序，学校实际印次有差异时可直接维护此文件。

选目从[人教社电子教材](https://jc.pep.com.cn/)的十册入口出发，参考[2026 年教材顺序核对清单](https://note.malinkang.com/life/child/2026-10-13-primary-school-poetry-plan/)，使用其标明的新版上册和当前公开下册范围；不将下册称为尚未发布的未来修订版。古代原文参考各条目的公开来源，教材节选及《墨梅》等用字单独调整。释义为本项目简明改写。目录是按这些公开资料整理，未宣称逐页人工复核全部最新版版权页。

原诗真人朗读来自[教育部、中央广播电视总台中小学语文示范诵读库](https://edu.cnr.cn/eduzt/ywkwsfsd/)，用于家庭学习。每首保留来源、朗读者、文件校验值和时长；音频、原录音和可重建输入曾按用户于2026-10-25的要求保存到个人 Azure 私有仓库，详见[完整诗词素材](../media/poetry/README.md)。此历史保存记录不代表取得公开重新分发授权。熏听版保留真人诗名、原有作者报幕和正文，去除年级、园地、章节及过长的配乐间隔。原录音没有读作者时才补一句作者名。释义选用微软 Edge 的自然女声 `zh-CN-XiaoxiaoNeural`（晓晓），语速 `-8%`、音高不变；作者补读使用同一声音。没有使用 Windows SAPI/Huihui。音频在电脑上通过加密的 HTTPS/WSS 连接提前生成，统一播放响度后复制到 U 盘；电视只播放本地文件，不需要语音引擎或联网合成。

在电脑上可运行 `python tools/prepare-poetry.py --destination <空目录>` 生成资源，需安装 ffmpeg。工具保留已有配置和音频；需要更新单首时，先自行备份并移走该首文件。不要覆盖自己修改的 `poems.json`。

准备熏听音频需要 Python、`edge-tts>=7.3.1` 和 ffmpeg。电脑先运行 `python tools/synthesize-poetry-edge.py --catalog <原诗词库/poems.json> --destination <新释义语音目录>`。再使用 `--kind author --segments <listening-segments.json> --destination <新作者语音目录>` 生成缺失的作者补读。电脑需要代理时可传 `--proxy <HTTP代理>`；默认串行生成，遇到限流等待，失败记录保留，`--reuse <旧输出目录>` 只复用文字、音色参数及哈希一致的已完成文件。

最后运行 `python tools/prepare-poetry-listening.py --library <原诗词库> --meanings <释义语音目录> --authors <作者语音目录> --segments <listening-segments.json> --destination <新的输出目录>`。范围文件按诗词编号记录真人报幕的 `introStart`、`introEnd`，正文的 `start`、`end` 秒数，原文件 `sourceSha256`，以及 `authorText`（已有人声作者时为空）。必须逐首核对边界，不能按统一秒数截去片头。工具检查原录音、合成语音文字和目录哈希，拒绝覆盖已有输出，以 -20 LUFS、-2 dBTP 为目标做两遍响度处理，并逐一解码；AAC 编码后的实际峰值需另行复测。先上传新音频及记录，校验哈希，再替换 `poems.json`；原录音和旧目录保留。修改诗意后须同步重做释义音频。公开真人资源中未找到对应当前87条简明释义的可核验录音，本次释义统一使用 Edge 自然语音。

主页每分钟顺序换一首，焦点在诗词上时停止轮换；左右选首，确定进入熏听，上返回日期区，下返回收藏应用。设置中的“主页诗词”仅控制主页显示，熏听和进度仍保留。

熏听页左侧原诗、右侧诗意，长内容可用遥控器聚焦后上下滚动。直接朗读诗名、作者和正文；原诗音频结束后等待 3 秒开始释义，释义音频结束后等待 5 秒进入下一首，最后一首之后循环。上一首、下一首、暂停/继续、按册选诗、从头开始均可直接操作；暂停后保留朗诵或释义阶段和剩余等待时间。频道加减或媒体上一首/下一首键也能切歌。离开页面或其他音频抢占时停止，不能在其他应用上方继续自动播放。关闭页面后记住当前首，不保存跨会话的句内时间。
