# 我的电视 · 赛博AI改造局

一个基于 [CleanYourTV](https://github.com/Gathin23/cleanyourtv) 的 Android TV 家庭桌面改版。把家里的照片、天气、日历和古诗词放在电视上，也可以按自己的习惯收藏常用应用。

> 当前版本面向 Sony BRAVIA ATV2 CN、Android 9 开发。其他型号和系统版本尚未充分验证。请保留原电视桌面和数据，确认适配后再使用。

## 功能

- **古诗词熏听**：在桌面打开诗词卡片，查看诗句与释义，播放真人示范朗读和释义，支持选诗、按年级册别选择、暂停及自动播放下一首。音频存放于 U 盘。
- **照片和壁纸**：从 U 盘读取照片作为首页背景或进入全屏相册；支持横竖图片适配和本地人脸位置裁剪。原图片不会被程序修改。
- **桌面信息**：显示时间、日期、农历、节气及天气，天气功能需要网络。
- **常用应用**：将喜欢的应用加入桌面收藏，使用遥控器操作。

部分功能受设备、存储权限和网络环境影响，具体表现以实际使用为准。

## 下载和安装

前往 [Releases 下载页面](https://github.com/leriocn/my-tv/releases) 获取安装包和配套素材。

1. 将 APK 下载到 U 盘，连接电视后，通过电视的文件管理器打开并安装。按电视系统提示处理第三方应用安装权限。
2. 下载诗词素材包，解压后将 `poetry` 文件夹放到 U 盘根目录。音频不包含在 APK 中；未放入素材时不能按完整方式播放朗诵与释义。
3. 下载壁纸包后，将其中图片放入 U 盘根目录的 `tv` 文件夹。目录不存在时自行创建；根据电视提示授予访问 U 盘的权限。
4. 打开桌面并按需设置照片、天气和收藏应用。是否设置为默认桌面由你自行选择。

目录示例：

```text
U盘根目录/
├── tv/                 # 壁纸和照片
└── poetry/
    ├── poems.json      # 诗词目录
    └── audio/          # 朗诵和释义音频
```

**安装包验证范围：**当前公开 APK 使用独立生成的调试签名，经过 283 项单元测试和 Lint，但本次构建尚未在实体电视上安装验证。已有同包名应用如果签名不同，可能无法直接覆盖安装；请不要为强行安装而卸载现有桌面或清除数据。历史设备验证见[维护说明](PERSONAL_MAINTENANCE.md)，不应视为本次 APK 的实机验收。
